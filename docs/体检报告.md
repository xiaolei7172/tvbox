### P2-5　Actions 工作流缺陷

`/.github/workflows/run.yml`：

| 问题 | 位置 | 影响 | 建议 |
|---|---|---|---|
| `git push -f origin master` | git-push job | 强推会**丢弃手动提交** | 改普通 `git push`，冲突时失败而非覆盖 |
| job 级 `continue-on-error: true` | xiaosa / fty job | 任务失败仍显示绿色，问题被掩盖 | 移除，改为步骤级容错 |
| 无 `concurrency` | 全局 | 与手动操作/多触发并发时互相覆盖 | 加 `concurrency: group: update, cancel-in-progress: true` |
| 无显式 `permissions` | 全局 | 新仓库默认 token 只读，push 可能 403 | 加 `permissions: contents: write` |
| 无失败告警 | 全局 | 源失效无法感知 | 加 `if: failure()` 通知步骤 |

> `actions/checkout@v7`、`upload-artifact@v7`、`download-artifact@v8` 均为**有效版本**（2026-10 发布），由 Dependabot 维护，无需降级。

### P2-6　fork 后的 Actions 状态

GitHub 对 fork 仓库默认**禁用** Actions。需手动到 `Settings → Actions → General → Allow all actions` 启用，否则每日更新不会执行。

启用后，定时任务会以**你的账号**额度运行（公开仓库免费额度足够，但 fork 不计入上游）。
